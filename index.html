🗂️ Rangement C

Range tes dossiers Windows (Téléchargements, Bureau, Documents…) en un clic. Tout se passe sur ton PC : aucun fichier n'est envoyé sur Internet.

Ton navigateur ne permet pas à une page d'accéder à tes dossiers. Ouvre cette page dans Microsoft Edge ou Google Chrome sur ton PC.

Quels fichiers sont ignorés ?

Les sous-dossiers existants (ils restent intacts), les raccourcis (.lnk, .url), les fichiers cachés (commençant par un point), desktop.ini, Thumbs.db et les téléchargements en cours (.crdownload, .part, .tmp). Si un fichier du même nom existe déjà dans le dossier de destination, il est renommé « nom (2) ». Rien n'est jamais supprimé.
